About LearnHub

Welcome to LearnHub! This is a simple educational project created to demonstrate how to build web applications using Django.

What This Project Covers

  • Creating Django views, URLs, and templates
  • Handling user forms and saving contact submissions
  • Storing data in a PostgreSQL database with Django models
  • Running the website with Docker and Docker Compose
  • Styling pages using Tailwind CSS

How It Works

Whenever you visit a page, Django receives the request and returns an HTML template. For example, when you submit a message on the Contact page, Django validates the data and stores it in the database before redirecting you to the confirmation page.
